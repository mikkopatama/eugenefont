INSTALL INSTRUCTIONS
--------------------

Windows: 
1. Run Eugene-Win-1.44.exe. The installer will require admin privileges and Windows User Account Control is going to ask "Do you want to allow this app from an unknown publisher to make changes to your device?". Choose "Yes" and carry on with the installation.

2. After running the installation, go to C:\Program Files\Common files\ and check whether you can find a folder named SMuFL\fonts\Eugene. If not, create the folders and copy Eugene.json to that folder.

3. Fully restart your notation app.


macOS:
1. Run Eugene-macOS-1.44.pkg
macOS might refuse to run the installer package since it's from a non-verified source. In this case go to "System Settings > Privacy and Security > Security"-section where Eugene font installer should now be mentioned and choose "Open anyway".

2. Check whether you can locate Eugene.otf and EugeneText.otf from /Library/Fonts.
If not, copy those files there from EugeneFont installation folder.

3. Check whether you can locate /Library/Application Support/SMuFL/Fonts/Eugene/Eugene.json. If this path doesn't exist, create it and copy Eugene.json from the installation folder.

4. Fully restart your notation app.
