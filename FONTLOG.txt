FONTLOG for Eugene music font

Eugene is a SMuFL-compliant OpenType music font inspired by the engraving style of E. Fromont
publications.
The font is licensed under the SIL Open Font License, Version 1.1.

https://github.com/mikkopatama/eugenefont


Change log
----------

13 May 2026 (v. 0.51)

Biggest update for a while. Jumped to version number 0.51, since the font now includes includes:
	- ALL common Flags from U+E240 to U+E24F
	- Almost ALL Dynamics letters from U+E520 to E+53D, excluding U+E526 dynamicNiente
	- Most commonly found g, f and c clef variants
	- ALL basic tuplet numbers from U+E880 to U0E889. 2, 3, 5 and 6 were traced from reference, all others were modified from time signature glyphs. Will need some fine tuning later.

- Modified:
	- All clefs were improved in shape and in ottava number glyph placement
	- Most time signature numbers were tweaked
	- Flags were made more consistent in style
	- noteheadHalf is now closer to reference

11 May 2026 (v. 0.507)

- Modified:
	- Created a new empty Glyphs project and imported all current 146 glyphs to get rid of some bugs in the .otf file. Dorico 6 shows everything correctly now, and Musescore loads the correct notehead glyphs instead of falling back to Bravura
	- Eugene.otf doesn't include Bravura fallback glyphs anymore, since missing glyphs are automatically replaced in both Dorico and Musescore.

- Known issues:
	- Currently Musescore seems to ignore the stemUpSE x-anchorpoint metadata, which causes the upside stemlines to be separate from the noteheads. Will try to rebuild the .json file or find some other solution.
